## 演示内容

- 左右独立开关，关闭保留档位和位置，Both 联动禁用；Stimulation 1–5、Expression 1–15，无零档。
- 最后一侧关闭提示仅提供“结束吸奶／取消”。
- 夜灯 4 个有效亮度档，保留开关、亮度记忆和自适应表现；移除自动开启夜灯设置。
- 旅行锁阻断使用白色底部引导，设备完整展示，标注心形键和 R 键，长按 5 秒解锁。
- 设置页暂时隐藏 Leak Detection 开关并保留实现，旧开关状态不影响后台记录和子首页 Guide。
- 吸奶中暂时隐藏检测发起、成功、失败及严重／轻微漏气提示组件，待稳压助手完善后统一上线；严重、轻微漏气仅后台记录，不提示、不阻断。结束后主动访问子首页展示原有 Fit Guide（保留项，仅调整后台静默事件记录的触发关系）。
- 提交奶量后保留在控制页。
- 中文触发器：轻微漏气、严重漏气（左侧／右侧／双侧）、旅行锁打开／关闭、温馨提示演示。

## 本地预览

纯静态 HTML/CSS/JavaScript，无需构建。

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8766/index.html?screen=control-manual-idle`。

模拟功能用于评审，不连接真实设备。保存奶量后的路由和样式还原等 Demo 修复不属于新增产品需求。
